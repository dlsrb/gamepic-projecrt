# 게임픽 추천 엔진 실험용 프로토타입

외부 라이브러리 없이 Python 3.10+ 만으로 돌아갑니다. 폴더째 PyCharm 프로젝트로 열면 됩니다.

| 파일 | 역할 |
|---|---|
| `data/games.json` | 게임 36개 예시 DB (태그는 실험용 예시라 실제 사용 전 검수 필요) |
| `config.py` | 태그 종류별 무게, 피드 반응 크기, 탐색 비율 등 **실험할 숫자** |
| `recommender.py` | 추천 엔진 (후보 거르기 → 점수 → 탐색 슬롯 → 피드 반응 반영) |
| `baseline.py` | 기존 기획서 공식 (비교용) |
| `evaluate.py` | 정답 세트 테스트. 새 방식 vs 기존 공식 비교 |
| `play.py` | 설문 → 피드에서 관심/넘김/스토어 클릭하며 추천 변화 직접 확인 |

## 실험 순서
1. `evaluate.py` 실행 → 현재 몇 개 케이스를 통과하는지 확인
2. `config.py` 숫자나 `games.json` 태그를 바꾸고 다시 실행 → 좋아졌는지 나빠졌는지 비교
3. `play.py` 로 직접 사용자처럼 써 보면서 이상한 추천이 나오면 그걸 `evaluate.py` 의 TEST_CASES 에 추가
