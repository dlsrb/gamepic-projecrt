## C12-a. 태그가 안 맞는 게임 정리
배경: 애니모(x-aniimos)는 자동 수집 태그가 RPG·멀티·오픈월드·무료+과금뿐이라 캐주얼 비선호로 안 걸러지고, 탐색 칸이 점수 순으로 채워져 매번 같은 게임이 뜸. 자동 수집 게임 151개 중 91개가 분위기 태그 0개.
1. **설문 맞춤 추천(홈 맞춤·추천 API)에서 태그 검수 안 된 게임 빼기**
   - 대상: `source='auto'`이면서 사람이 검수 안 한 게임 (검수 표시 컬럼이 없으면 `games.tags_checked` 0/1 추가)
   - 랭킹·신작·검색·상세에는 그대로 나옴 (맞춤 추천에만 안 나옴)
   - 적용 전/후 시뮬 사용자별 후보 수 표. 후보가 9개 미만이 되면 혼자 바꾸지 말고 보고
2. **화면 태그 칩**: 게임 카드·상세에 보이는 태그는 **검수된 게임의 태그만**. 미검수 게임은 장르 하나만 표시
3. **태그 검수 도구** `scripts/tag_review.py`
   - `--export` → `data/tag_review.csv` (id, 이름, 개발사, 스토어 설명 앞 200자, 지금 태그, 제안 태그 빈칸, checked 빈칸)
   - `--import` → CSV에서 본인이 채운 태그로 바꾸고 `tags_checked=1`
   - 제안 태그를 LLM으로 채우는 기능은 이번엔 넣지 않음 (MCP 가점 작업 때 검토). 대신 내보낼 때 홈 노출이 많은 순(설치 수·차트 순위)으로 정렬
4. **애니모는 바로 고침**: 수집형RPG·귀여움·캐주얼·3D 추가, `tags_checked=1` (태그 이름은 지금 태그표에 있는 것만)
5. **탐색 칸 무작위화**: 탐색 칸(20%)을 점수 순으로 채우지 말고, 조건을 통과한 후보 상위 N개(예: 15) 중 무작위. 같은 사용자가 새로고침할 때마다 조금씩 달라짐. N은 `reco_config.py`에

## C12-c. 인기 랭킹 카테고리
- 랭킹 페이지 탭: **전체 / Google Play / App Store / RPG / 시뮬레이션 / 액션** (장르 탭 목록은 설정 파일로, 나중에 추가 가능)

## C12-e. 자동 카테고리 (검색·화면 배지)
태그와 별개인 **자동 배지**로 처리 (검색어로도 찾을 수 있게: "신작", "인디", "인기", "급상승"을 `search_synonyms.json`·검색 해석에 연결).
1. **신작**: 출시일이 최근 **30일 이내** (날짜 없는 게임 제외). 신작 페이지(2026년작)와는 별개 기준
2. **인디**: Google Play 설치 수 **10만 이하**(`installs <= 100000`). 설치 수가 없는 iOS 전용 게임은 기존 `is_indie` 값으로. 기존 `is_indie`와 어떻게 합칠지 결정에 적기
3. **인기 급상승**: 
   - 매일 자동 수집 때 게임별 숫자 **스냅샷 표** 추가 (`game_stats_daily`: 날짜, 설치 수, 별점 수, 차트 순위 양쪽)
   - 점수 = 최근 7일(또는 30일) **별점 수 증가율** + **차트 순위 상승** + **게임픽 검색 횟수**(`search_logs`) + 상세 조회·따봉 증가. 무게는 `reco_config.py`, 식은 결과에 적기
   - Play 설치 수는 구간 값(10만+, 100만+)이라 증가 판단에는 구간이 올라간 경우만 사용
   - 기록이 7일 미만이면 배지를 안 붙이고 "기록 쌓는 중"으로 둠 (테스트에서 날짜 조작으로 확인)
4. **인기**: 인기 랭킹(C12-c 전체) **1~30위**면 배지
- **한계 (결과에 적기)**: 배포는 다시 배포하면 DB가 초기화되므로 스냅샷 기록도 사라짐 → 다시 배포한 날부터 7일간은 급상승 배지가 없음. seed에 로컬 스냅샷을 넣을지 결정에 적기

## C12-f. UI 다듬기 ("AI가 만든 티" 줄이기)
본인 피드백: UI에 AI가 만든 티가 남. 아래를 점검하고 바꾼 것을 화면별로 적기 (전후 캡처를 `docs/ui_c12/`에)
- 장식용 이모지(👍🔥✨ 등) → 선 아이콘(SVG) 하나로 통일하거나 없앰
- 모든 요소가 같은 둥근 카드 + 그림자인 구성 → 목록은 구분선, 카드는 꼭 필요한 곳만
- 의미 없는 그라데이션·반짝임·과한 배지·"✨추천" 같은 문구 정리
- 글자 크기 단계는 3~4개로, 굵기 남용 줄이기, 회색 글자 대비 확인
- 문구: "~해 보세요!", "완벽한" 같은 홍보 말투 → 짧고 담백하게
- 색은 로고 남색 계열 하나 + 강조색 하나로
- 본인이 따로 지적하는 화면이 생기면 그것부터
