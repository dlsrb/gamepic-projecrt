# C12-j 지시 — 태그 정확도: 스토어 분류로 자동 보강 + AI 초안 기록 (11/23 채팅)

> 배경: 미검수 자동 수집 게임이 계속 늘어 사람이 전부 검수할 수 없음 (교수님 질문 "이걸 다 검수할 거냐"). 결정:
> - 홈에 많이 보이는 50개는 **Claude가 태그 초안 + 확신도**를 만들었고, 확신 높음·중간 42개는 `checked=1`로 자동 승인 (`data/tag_review.csv`, 사람이 게임을 해 보고 검수한 것 아님). 낮음 8개는 미검수로 둠
> - 앞으로 들어오는 게임은 **스토어 자체 분류로 자동 보강** (이번 작업)

## 1. AI 초안 가져오기 + 출처 기록
- `python scripts/tag_review.py --import --dry-run` → 건너뛰는 줄과 이유 확인 → `--import`
- 태그를 누가 붙였는지 구분: `games.tag_source` 추가 (`auto` 자동 수집 규칙 / `store` 스토어 분류(아래 2) / `ai` AI 초안 승인 / `human` 사람). 이번 42개는 `ai`, 직접 넣은 기존 36개는 `human`, 애니모는 `human`
- `tags_checked` 의미는 그대로(맞춤 추천에 우선 사용). `ai`도 checked로 침
- README·발표에서 "AI 초안 + 확신도 기준 자동 승인"이라고 쓸 수 있게 결과에 숫자 남기기 (출처별 게임 수)

## 2. 스토어 분류로 태그 보강 — **먼저 조사, 보고 후 구현**
1. 조사 (코드 바꾸기 전):
   - `google-play-scraper`(지금 1.2.7)의 `app()` 결과에 장르 말고 더 있는지: `categories`(여러 개), `genreId`, 그 밖의 분류 필드. 우리 DB 게임 10개(장르 다양하게)로 실제 값 표 만들기
   - Play 스토어 페이지의 태그 칩("캐주얼", "싱글 플레이어", "오프라인", "귀여운" 같은 것)이 라이브러리로 오는지. 안 오면 공식 경로가 없는 것으로 보고 **페이지 직접 긁기는 하지 않음** (깨지기 쉽고 약관 문제)
   - App Store `lookup`의 `genres`(여러 개) 값도 같은 10개로
   - 표와 함께 "쓸 수 있는 정보 / 우리 태그로 바꿀 수 있는 범위"를 PROJECT.md에 적고 **여기서 멈추고 보고**
2. (본인 승인 후) 구현 방향 미리 적어 둠:
   - 스토어 분류 → 우리 태그 대응표를 `data/store_genre_map.json` 확장 또는 새 파일로
   - 새 게임 수집 때, 그리고 `tag_source='auto'`인 기존 게임에 한 번 적용 → `tag_source='store'`
   - `store` 태그 게임을 checked로 칠지는 조사 결과 보고 정함
