## 8. 발견한 문제

**자동 점검**

- 같은 게임 따봉 중복 행: 0개 (같은 게임에 따봉을 두 번 이상 누른 경우 8번 — API가 한 번만 기록해야 0)
- 비선호 위반: 홈 0 · 이달의 게임 0
- 결과 0개 검색어: 39종류

**분석 (Code가 숫자를 보고 쓴 것, `docs/sim_notes.md`)**

시뮬레이션 숫자를 보고 Code가 쓴 분석 (11/23). **고치지는 않았고 제안만** — 고칠지는 본인 결정.

1. **피드백 그룹이 방문할수록 나아지는 모습이 뚜렷하지 않음** (숨은 취향 일치 1회차 88.6% → 8회차 85.3% → 10회차 90.4%, 따봉률도 random 8.7% · survey 8.2% · feedback 7.7%로 비슷)
   - 원인 추정: ① 설문 3번에서 장르를 고르면 그 장르만 후보(강한 필터)라 어떤 순서로 보여 줘도 숨은 취향과 대체로 맞음 → random 그룹도 86% ② 따봉·스토어 이동·관심 없음을 한 게임은 다시 추천하지 않아서, 잘 맞는 게임부터 빠져나감 ③ "숨은 취향 일치"를 태그 1개 이상 겹침으로 재서 기준이 느슨함
   - 제안: 고치기보다 **재는 법을 먼저 바꾸기** — 겹치는 태그 2개 이상·회차별 따봉률로 다시 보고, 그래도 차이가 없으면 반응 무게(`FEEDBACK_DELTA`)를 키우는 실험
2. **"급상승" 검색이 늘 0개** (`급상승` 단독 29번 등 0개 검색어의 대부분)
   - 원인: 급상승 배지는 하루 1번 스냅샷이 7일 이상 쌓여야 계산되는데, 지금 스냅샷이 1일뿐 → "기록 쌓는 중"이라 배지 게임이 없음 (설계대로). 사용자 입장에선 이유 없이 결과가 비어 보임
   - 제안: 기록 쌓는 중일 때 검색어 "급상승"이면 결과 칸에 "급상승은 기록을 쌓는 중이에요 (7일 뒤부터)" 안내, 또는 그동안은 "인기"로 대신 보여 주기
3. **두 단어 AND 검색이 자주 0개** (`스토리 감성`, `무과금 혼자`, `어드벤처 싱글`, `힐링 짧게` …)
   - 원인: 검색은 단어를 모두 만족(AND). 태그가 드문 조합이 많음 — 예: 감성 태그 게임 8개 · 스토리중심 28개인데 둘 다 붙은 게임 0개. 자동 수집 게임 상당수가 분위기 태그가 없음
   - 제안: 모두 만족하는 게임이 0개면 "일부만 맞는 게임"을 맞는 단어 수 순으로 보여 주기 (지금은 빈 화면). 태그 검수(AI 초안 다음 묶음)도 효과 있음
4. **이달의 게임이 시뮬 전후로 똑같음**
   - 원인: 이달의 게임 = 이번 달 스토어 차트 평균(스냅샷) + 급상승. 게임픽 안의 따봉·조회는 급상승 점수에만 들어가는데 급상승이 아직 계산 전이라, 사용자 활동이 반영될 길이 없음 (설계대로)
   - 제안: 급상승이 계산되기 전에도 이번 달 게임픽 따봉 수를 약하게 섞기 (예: 0.1 무게) — 사용자 테스트 기간에 "내가 누른 게 반영되는" 느낌
5. **전략·SLG 유형의 숨은 취향 일치가 35.5%로 낮음**
   - 원인: 전략 장르 게임 35개 중 태그 검수된 게임이 8개뿐 → 맞춤 추천 후보가 적고, 모자라면 미검수로 채우는데(C12-i) 미검수 전략 게임 태그(실시간전략·기지건설·밀리터리)가 비어 있는 경우가 많음
   - 제안: 다음 AI 초안 묶음을 **검수 게임이 적은 장르 먼저**(전략 → …)로
6. **홈 대체 동작(60% 기준 미달) 방문 28.2%**
   - 원인: 넓은 취향·장르를 안 고른 유형은 60%를 넘는 게임이 적음 (C12-i 채우기 뒤에도). 화면엔 "취향 60% 이상인 게임이 적어 가까운 순서로 보여요" 안내가 뜸
   - 제안: 그대로 두되 유형별 대체 동작 비율을 다음 시뮬에서 따로 재기
7. **미검수(auto) 게임이 홈 추천의 27%** — C12-i(모자라면 미검수로 채움, 홈 60% 칸도)의 결과. 숨은 취향 일치는 오히려 높음(93.8%, 태그가 장르 정도라 겹치기 쉬움). 문제라기보다 참고. 검수가 쌓이면 줄어듦
8. 그 밖에 이상 없음: 비선호 위반 0, 같은 게임 따봉 중복 0(8번 다시 눌렀지만 한 번만 기록), 사용자 300명 뒤에도 API 응답 중앙값 그대로(28~39ms), 95%는 최대 +12ms. 캐주얼 유형의 "숨은 비선호 포함" 22.8%는 숨은 비선호(PvP)를 설문에 안 밝혔거나 "딱히 없어요"를 고른 사람 몫이라 엔진 문제 아님
