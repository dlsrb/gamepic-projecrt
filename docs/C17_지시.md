# C17 지시 — 설문 맞춤 추천은 취향 80% 이상만 (11/23 채팅)

> `PROJECT.md`와 같이 읽고 시작. 결과는 PROJECT.md 4.11 "결과 (C17)", 지시 외 결정은 따로.
> 본인 피드백: 홈 "설문 맞춤 추천"에 취향 20%대 게임이 섞여 나옴 → **80% 이상만** 보여 주고, 적으면 적은 대로 그것만.
> C16(규모 실험)과는 별개. C16 확장 기준(아이콘 축소·인기/인디·한국어 지원)은 나중에 C16-2로.

## 지금 왜 낮은 %가 나오나 (확인 후 결과에 적기)
- 홈 맞춤 칸 기준이 60%(`min_match`)이고, 그 밖에도 낮은 %가 들어오는 길이 있음:
  1. 탐색 칸(20%): 취향 % 기준 없이 인디·남은 후보로 채움
  2. 대체 동작: 60% 통과가 `MIN_MATCH_FLOOR` 미만이면 기준 없이 점수 순으로 채움
  3. C12-i 채우기: 검수 게임이 모자라면 미검수로 채움
- 각각이 실제로 몇 장씩 섞이는지 시뮬 유형 몇 개로 먼저 세서 표로

## 바꿀 것
1. **홈 "설문 맞춤 추천" 칸 = 취향 80% 이상만**
   - 기준값 `HOME_MIN_MATCH = 80` (`reco_config.py`)
   - 80% 미만은 어떤 경로(탐색·대체 동작·미검수 채우기)로도 이 칸에 넣지 않음 → **모자라면 모자란 대로** (0~N장)
   - 순서는 지금처럼 엔진 점수 순
2. **부풀려진 %를 막기**: 태그가 적은 미검수 게임은 "퍼즐" 하나만 맞아도 %가 높게 나옴(예: 태그 3개 미검수 게임 63%, 검수 게임 36%)
   - 80% 칸에는 **검수된 게임(human·ai) + 태그 `HOME_MIN_TAGS`(4) 이상**인 게임만
   - 그래도 미검수·store 게임이 80%를 넘는 경우가 있으면 결과에 사례로 적기
3. **0~2장일 때 화면**
   - 칸 제목 아래 담백한 안내: "취향에 80% 이상 맞는 게임이 아직 N개예요. 따봉을 누를수록 더 정확해져요"
   - 0장이면 카드 대신 안내 + "인기 랭킹 보기" 링크 (다른 게임으로 채우지 않음)
4. **탐색 칸 처리**: 맞춤 추천 칸에서 탐색 칸을 빼고, 원하면 맞춤 칸 아래에 **별도 섹션 "새로 발견하기"**(인디·신작, % 표시 없이 "취향과 다를 수 있어요")로 분리. 섹션 자체가 비면 숨김
   - 탐색 섹션에도 비선호(연관 포함) 제외는 그대로
5. 바뀌지 않는 것: 추천 엔진 점수 규칙, 이달의 게임, 랭킹, 검색, 상세 "비슷한 게임"(지금 규칙 그대로), MCP(`recommend_games`는 그대로 두되 결과에 %가 있으니 그대로)
   - 단 `/api/feed?section=match`를 MCP나 다른 곳이 쓰면 영향 확인
