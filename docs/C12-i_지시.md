# C12-i 지시 — 맞춤 추천 후보 부족 해결 (11/23 채팅, C12 결과의 결정)

> C12 결과 "결정이 필요한 것"에 대한 답: **1(검수 먼저) + 2(부족하면 미검수로 채움)를 섞는다.** 3(태그 4개 이상이면 검수로 봄)은 하지 않음 — 애니모도 태그 4개였는데 틀렸음.
> 애니모 장르는 RPG 그대로 (귀여움 태그로 캐주얼 비선호에 걸림). 나머지 C12 지시 외 결정 15건은 승인.

## 1. 부족하면 미검수 게임으로 채우기
- 맞춤 추천(홈 맞춤 칸·추천 API)은 지금처럼 **검수된 게임 먼저**
- 검수된 후보가 **9개 미만**(기준값은 `reco_config.py`, 기존 `MIN_MATCH_FLOOR`와 같은 값이면 그걸 씀)이면 **미검수 게임으로 채움**
  - 미검수 게임도 비선호(연관 태그 포함)·이미 본 게임 거르기는 똑같이
  - 채우는 순서: 점수 순. 같은 점수대면 태그 수 많은 것·인기 순위 높은 것 먼저
  - 채운 게임 카드는 따로 표시하지 않음 (태그 칩은 C12 규칙대로 장르 하나만)
- 이 때문에 홈이 대체 동작으로 넘어가는 경우가 줄어야 함 → **C12 전/후 표에 "C12-i 후" 열을 추가** (시뮬 사용자별 후보 수, 홈 슬라이드 장 수, 대체 동작 여부)

## 2. 본인 검수 준비
- `python scripts/tag_review.py --export`로 `data/tag_review.csv`를 만들되 **상위 50개만** 나오는 옵션(`--top 50`)이 없으면 추가
- CSV 맨 위에 채우는 방법 한 줄 설명 (태그 이름은 태그표에 있는 것만, 장르는 하나, 쉼표로 구분, 검수 끝난 줄은 checked에 1)
- 태그표 전체(종류별 이름 목록)를 `docs/tag_list.md`로 만들어 본인이 보면서 채울 수 있게 (파일 이름 ASCII)
- `--import` 때 없는 태그 이름·장르 2개 이상이면 그 줄은 건너뛰고 이유를 출력
